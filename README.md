## Постановка задачи

Цель задания - создание консольного приложения на C++, моделирующее обработку задач несколькими потоками. Требуется создать очередь из задач, с которой будут работать N рабочих потоков и выводить лог в консоль по завершении работы.

## Описание реализации

В потоке main, создаётся потокобезопасная очередь TaskQueue, затем создается N рабочих потоков и в очередь добавляется 20 задач. N потоков через функцию ProcessTask обращаются к очереди и параллельно обрабатывают её данные. В программе реализуется архитектурный паттерн "Производитель-Потребитель".

Чтобы не допустить возникновения race condition (состояния гонки) в программе используется `std::mutex`. При любом обращении к данным, программа оборачивает их в `std::lock_guard` или `std::unique_lock`, таким обеспечивается потокобезопасность очереди. Аналогично для правильного вывода в консоль вводится отдельный мьютекс `coutmutex`.

`std::condition_variable` в программе используется для того, чтобы избежать активного ожидания (busy wait). Вместо того, чтобы бесконечно ждать выполнения условия, потоки вызывают метод `wait()`. Потоки пробуждаются через `notify_one()`, когда появляется новая задача, или через `notify_all()`, чтобы корректно завершить программу. Для этого же в конце программы для каждого из потоков вызывается метод `join()`
